# Косынка — изометрический пасьянс на raylib

«Косынка» (Klondike) с изометрической 3D-камерой, написанная на C99 поверх
[raylib](https://www.raylib.com/) (OpenGL 3.3, GLFW/X11). Цель — запускаться на
любом x86_64 Linux, включая дистрибутивы со старой glibc (Linux Mint 20/21/22,
Ubuntu 18.04+, Debian 10+).

> **Внимание: ассетов в репозитории нет.**
> Картинки, звуки и шрифт удалены — это сторонние материалы, права на которые
> автору проекта не принадлежат. В репозитории остаётся только исходный код,
> скрипты сборки и конфигурация. Без собственных файлов в `assets/` игра
> соберётся, но запустится с заглушками raylib вместо карт, стола и звуков.
> Список нужных файлов — в разделе «Ассеты».

## Возможности

- изометрический стол, карты с подсветкой по нормалям, анимация перелёта;
- правила Klondike: 7 столбцов, 4 дома, выдача по 1 или 3 карты;
- отмена ходов, советник-подсказка (не зацикливается на пройденных позициях),
  авто-сбор, счёт, таймер партии;
- статистика в `solitaire_stats.json`: винрейт, серии побед, среднее время,
  журнал последних партий;
- камера настраивается без пересборки через `solitaire.conf`.

## Ассеты

В репозитории их нет — положите свои файлы следующей структуры:

```
assets/fonts/main.ttf                  шрифт интерфейса (TTF)
assets/jpg/felt.png                    фон стола (иначе берётся feltx2.jpg)
assets/cards/<suit>_<rank>.png         карты: 4 масти × A,2..10,J,Q,K
assets/cards/<suit>_<rank>_normal.png  карта нормалей для подсветки (необязательно)
assets/cards/back01.png                рубашка карт
assets/ogg/<имя>.ogg                   7 звуков (точные имена — game/render.c:137-143)
```

Имена мастей и рангов формируются `SuitName()` / `RankName()` в
`game/render.c`. Отсутствующие текстуры и звуки raylib молча подменяет
заглушками (белый квадрат, тишина) — игра не падает. Каталог `assets/`
внесён в `.gitignore`, так что восстановленные файлы обратно в git не попадут.

## Сборка

Зависимости хоста: `gcc`, `make`, `python3`, `dpkg-deb`, `tar`, `curl`.
Скрипты сами скачивают glibc/raylib в `.build/` и исходники игры не меняют.

```
./build_portable_mint.sh     # итог: dist/solitaire-linux-x86_64/ + .tar.gz
```

- `build_portable_mint.sh` — компилирует raylib и игру против скачанной
  **glibc 2.31** (Debian 11 bullseye), raylib линкуется статически. Бинарник
  требует не выше `GLIBC_2.29`, работает на Mint 20+ и любом glibc ≥ 2.30.
- `build_portable.sh` — максимальная совместимость: в пакет кладётся
  собственная glibc + X11-библиотеки, запуск через `run.sh` с нашим `ld.so`
  (Ubuntu 18.04+, Debian 10+, CentOS 7+). Пакет тяжелее.

Единственная внешняя зависимость обоих вариантов — `libGL.so.1` (Mesa):
её нельзя влинковать, GLFW грузит драйвер через `dlopen`.

## Запуск

```
./solitaire            # из каталога проекта
cd dist/solitaire-linux-x86_64 && ./run.sh   # из готового пакета
```

Важно: пути к `assets/` и `game/*.vs|*.fs` заданы относительными, поэтому
процесс должен стартовать из корня проекта (или пакета). При запуске из
другого каталога шейдер не загрузится — raylib молча подставит дефолтный, и
карты начнут перекрывать друг друга непрозрачными углами.

Управление:

| Ввод | Действие |
|---|---|
| ЛКМ по карте | взять / положить |
| ПКМ по пустому месту, двойной клик | авто-сбор |
| `N` | новая игра |
| `U` / `Ctrl+Z` | отмена хода |
| `H` | подсказка |
| `D` | выдача 1 / 3 карты |
| `Space` | авто-сбор |
| `S` | панель статистики |
| `Esc` | закрыть панель |

## Настройки камеры — `solitaire.conf`

Файл ищется в текущем каталоге, затем рядом с бинарником. Формат
`ключ = значение`, комментарии `#` и `;`, векторы через запятую. Нет файла —
действуют значения по умолчанию.

```
camera.position   = 0, 32, 26
camera.target     = 0, 0, 0
camera.up         = 0, 1, 0
camera.fovy       = 12.48      # ortho: высота видимой области в мировых единицах
camera.projection = ortho      # ortho | persp
```

Камера ортографическая, поэтому `camera.fovy` — не угол, а высота кадра в
мировых единицах: на маленьком экране/узком окне карты жмутся к краям —
увеличивайте `fovy` (например, до 14–15). Невалидное значение игнорируется с
предупреждением в лог.

## Структура

```
main.c            точка входа, парсинг solitaire.conf, окно и цикл кадра
game/game.h       типы состояния игры, ассетов, статистики; общий API
game/rules.c      правила Klondike, ходы, отмена, подсказки, счёт
game/layout.c     раскладка стопок и карт в мире (layout.h)
game/render.c     загрузка ассетов, шейдеры, отрисовка стола, карт и HUD
game/handle.c     мышь/клавиатура, пикинг карт через GetScreenToWorldRay
game/anim.c       анимация перелёта карт
game/solver.c     советник: поиск полезного хода, память позиций
game/stats.c      чтение/запись solitaire_stats.json
game/lighting.vs|fs  шейдеры карт (подсветка + discard по альфе)
assets/           в репозиторий не входит — свои карты/шрифт/звуки (см. «Ассеты»)
solitaire.conf    настройки камеры
build_portable*.sh  сборка переносимых пакетов
```

## Известные ограничения

- Linux/X11; под Wayland работает через XWayland.
- Пути к ресурсам относительные — см. «Запуск».
- Статистика пишется в текущий каталог (`solitaire_stats.json`).
- Внешний драйвер OpenGL обязателен, софтверный рендер (llvmpipe) работает,
  но FPS ниже.
